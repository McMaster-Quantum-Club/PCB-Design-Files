The following repository is the McMaster NEUDOSE Altium PCB Project Template.

To use this template, please go to [McMaster NEUDOSE github](https://github.com/McMasterNEUDOSE) and create a `new respository`. 
In the `create a new repository`, under `respository template` select this repository from the drop down. 

Refer to [Altium Designer 101](https://confluence2.mcmasterneudose.ca/display/HowTos/Altium+Designer+101) for more instruction. 

Please change REAMME.md as needed once a new repository has been created.
